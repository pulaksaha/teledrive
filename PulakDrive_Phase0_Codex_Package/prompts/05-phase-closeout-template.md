# Codex Prompt 05 — Phase closeout

Prepare a phase closeout report. Do not begin the next phase.

Include:
1. Phase objective and scope.
2. Completed work and intentionally deferred work.
3. Files changed.
4. Commands run and actual results.
5. Tests passed, failed, skipped, and not run.
6. Independent review findings and remediation status.
7. Security, privacy, and data-integrity assessment.
8. Performance/resource measurements and methodology, if applicable.
9. Acceptance criteria table with evidence for each criterion.
10. Known limitations and residual risks.
11. Documentation/ADR/roadmap updates.
12. Gate recommendation: PASS / PASS WITH EXCEPTIONS / FAIL.

A PASS WITH EXCEPTIONS requires the user's explicit acceptance of each exception. Do not start the next phase until the user explicitly authorizes it.
